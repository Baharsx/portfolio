# Soheil Portfolio

Personal website of **Soheil** — early Web3 contributor, builder, and creator. Active in crypto since 2020.

**Live:** [soheil-portfolio-pi.vercel.app](https://soheil-portfolio-pi.vercel.app/)

The site covers two complementary sides of my work:

- **Web3 / creator:** early ecosystem participation, community and creator campaigns, educational content, Limitless ambassadorship, and selected published work.
- **Builder:** products and experiments including [MemeVerse](https://github.com/Baharsx/memeverse) and [Orrery](https://github.com/Baharsx/Orrery).

A separate [media kit](https://soheil-portfolio-pi.vercel.app/media-kit.html) provides collaboration formats and campaign evidence.

## Stack

Static HTML, CSS and JavaScript. Deployed on Vercel from `main`.

## Local preview

```bash
python3 -m http.server 4173
```

Visit `http://localhost:4173`.

## Maintenance notes

- Audience numbers are **dated snapshots**, not live counts. Update the number and date in both `index.html` and `media-kit.html` when a new verified snapshot is available.
- Only publish campaign results and engagement numbers with a link or other supporting evidence.
- Keep the homepage, media kit, and public X bio aligned on current roles and partnerships.
