# Portfolio

Personal site of **Soheil SL** — builder and onchain researcher.

**Live:** [soheil-portfolio-pi.vercel.app](https://soheil-portfolio-pi.vercel.app)

HTML, CSS, a little JavaScript. Deployed on Vercel.
